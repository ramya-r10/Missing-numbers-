Square and Cube Calculator in C
Overview

This project is a simple C program that calculates the square and cube of a given number. It also includes an interactive feature where users can practice solving missing-value questions related to squares and cubes.

Objectives:

 * Demonstrate the use of scanf() and printf().
 * Perform square and cube calculations.
 * Practice conditional statements (if-else).
 * Improve understanding of basic arithmetic operations in C.

Features:

 * Accepts user input using scanf().
 * Calculates square and cube values.
 * Displays missing-value questions for practice.
 * Validates user answers and provides feedback.
* Simple and beginner-friendly implementation.

Technologies Used:

 * C Programming Language
 * Standard Input/Output Library (stdio.h)
